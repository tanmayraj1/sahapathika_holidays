# Sahapathika_Holidays.dc

## Accessibility

The site targets WCAG 2.2 AA and ships its own accessibility toolbar (`a11y/`). Fixes inside the 31 page templates are applied by `tools/a11y-inject.js`, so they land identically in every page. Read [docs/ACCESSIBILITY.md](docs/ACCESSIBILITY.md) before changing page markup, colours or scripts. The public statement is [accessibility.html](accessibility.html).
